### 1.2.1 تبدیل واحد (Unit Decomposition)

سیستم از ثبت و تبدیل واحدهای اندازه‌گیری پشتیبانی می‌کند تا فروشنده بتواند موجودی را به صورت بسته‌بندی بزرگ وارد کند و سیستم خودکار به واحد کوچک‌تر تبدیل نماید.

**مثال‌ها:**
```
1 جین   = 12 عدد
1 کیلوم = 1000 گرم
1 کامیون سنگ (نوع A) = 20,000 کیلوگرم
1 کارتن  = 24 عدد
```

**جدول تعریف نسبت واحدها (`unit_conversions`):**

```sql
unit_conversions
  id         bigint PK
  name       text         -- نام واحد (مثلاً "جین")
  base_unit  text         -- واحد پایه (مثلاً "عدد")
  factor     decimal      -- ضریب تبدیل (مثلاً 12)
  category   text         -- دسته (مثلاً "پارچه" / "سنگ" / "عمومی")
  is_active  boolean
  created_at, created_by, ...  -- Audit Fields
```

**نحوه استفاده هنگام ثبت موجودی:**
```
فروشنده می‌گوید: "5 جین اضافه می‌کنم"
سیستم: 5 × 12 = 60 عدد موجودی ثبت می‌شود

فروشنده می‌گوید: "3 کامیون سنگ نوع فلان"
سیستم: 3 × 20,000 = 60,000 کیلوگرم موجودی ثبت می‌شود
```

هر محصول می‌تواند به یک یا چند `unit_conversion` متصل باشد. تعریف این روابط در پنل ادمین انجام می‌شود.

### 3.3 قیمت‌گذاری همکاران (Reseller Pricing)

همکاران (نقش Reseller) می‌توانند در سطوح اعتباری مختلف قرار گیرند و به ازای هر سطح، تخفیف متفاوتی دریافت کنند:

```
سطح اعتباری ۱  → ۵٪ تخفیف از قیمت عادی
سطح اعتباری ۲  → ۸٪ تخفیف از قیمت عادی
سطح اعتباری ۳  → ۱۲٪ تخفیف از قیمت عادی
سطح اعتباری ۴  → ۱۵٪ تخفیف + شرایط ویژه
```

**جدول سطوح اعتباری (`reseller_tiers`):**
```sql
reseller_tiers
  id             bigint PK
  name           text       -- نام سطح (مثلاً "نقره‌ای")
  credit_level   int        -- عدد سطح (1, 2, 3, ...)
  discount_pct   decimal    -- درصد تخفیف
  description    text
  is_active      boolean
  created_at, created_by, ...
```

**اتصال محصول به سطوح تخفیف:**
- هر محصول می‌تواند برای هر سطح اعتباری، تخفیف اختصاصی داشته باشد
- یا از نرخ پیش‌فرض سطح استفاده کند

### 3.4 گروه‌های قیمتی (Price Groups)

امکان تعریف گروه‌های قیمتی سراسری برای سیستم، که محصولات می‌توانند به آن‌ها اختصاص یابند:

```
گروه قیمتی A → محصولات الکترونیکی: ۵٪ تخفیف اضافه
گروه قیمتی B → محصولات فصلی: ۱۰٪ تخفیف
گروه قیمتی C → محصولات ویژه VIP: فقط برای اعضای سطح Gold
```

**ویژگی‌ها:**
- گروه‌های قیمتی در **سطح سیستم** تعریف می‌شوند (Admin)
- هر محصول می‌تواند به یک گروه قیمتی اختصاص یابد
- با یک دکمه، تنظیمات گروه قیمتی برای هر محصول **غیرفعال** می‌شود (override)
- نیازی به تعریف مجدد قوانین قیمتی به ازای هر محصول نیست

**جدول گروه‌های قیمتی (`price_groups`):**
```sql
price_groups
  id              bigint PK
  name            text
  discount_type   enum     -- percentage | fixed
  discount_value  decimal
  applicable_to   jsonb    -- { "roles": [...], "min_order": ... }
  is_active       boolean
  created_at, created_by, ...

product_price_group
  product_id      bigint FK
  price_group_id  bigint FK
  is_override     boolean  -- اگر true، قوانین گروه برای این محصول اعمال نمی‌شود
```

products

attributes
  id, name, type, scope, is_filterable

-- مقادیر اتریبیوت
attribute_values
  id, attribute_id, value, label, color_hex, sort_order

-- تنوع‌های محصول
product_variations
  id, product_id, sku, price, sale_price

  attributes JSON ({"رنگ": "قرمز", "سایز": "42"})

-- موجودی در انبار

  id, product_id, variation_id, warehouse_id

warehouses
