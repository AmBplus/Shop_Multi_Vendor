### 3.2 فروش محصول مشترک

> **مفهوم کلیدی:** در این سامانه یک محصول می‌تواند توسط چند فروشنده عرضه شود. هر فروشنده قیمت و موجودی مستقل خود را دارد.

```
Product (محصول پایه)
    ├── VendorOffer (عرضه فروشنده ۱) → قیمت: ۱۲۰,۰۰۰ تومان
    ├── VendorOffer (عرضه فروشنده ۲) → قیمت: ۱۱۵,۰۰۰ تومان
    └── VendorOffer (فروشگاه اصلی)  → قیمت: ۱۱۸,۰۰۰ تومان
```

**نکته:** اگر فقط یک فروشنده داشته باشیم (مثلاً فقط فروشگاه اصلی)، بخش "انتخاب فروشنده" در صفحه محصول نمایش داده نمی‌شود.

## 7. معماری پیشنهادی

### 7.1 ساختار جداول

```sql
-- جدول اصلی فروشندگان
vendors
  id, user_id, brand_name, slug, logo, banner
  type (individual/company), status
  commission_type, commission_value
  created_at, approved_at

-- عرضه‌های فروشنده (هر فروشنده می‌تواند همان محصول را بفروشد)
vendor_offers
  id, vendor_id, product_id
  price, sale_price, stock, sku
  preparation_days, shipping_methods
  status, created_at

-- کیف پول فروشنده
vendor_wallets
  id, vendor_id
  total_balance, available_balance, pending_balance

-- تراکنش‌های مالی
vendor_transactions
  id, vendor_id, order_id, type
  amount, commission, net_amount
  status, settled_at
```

### 7.2 API اصلی فروشنده

```
POST   /api/vendor/register          # ثبت‌نام
GET    /api/vendor/profile           # مشاهده پروفایل
PUT    /api/vendor/profile           # ویرایش پروفایل
GET    /api/vendor/dashboard         # داشبورد
GET    /api/vendor/orders            # سفارشات
GET    /api/vendor/products          # محصولات
POST   /api/vendor/products          # افزودن محصول
PUT    /api/vendor/products/:id      # ویرایش محصول
GET    /api/vendor/wallet            # کیف پول
POST   /api/vendor/wallet/withdraw   # درخواست برداشت
GET    /api/vendor/reports/sales     # گزارش فروش
GET    /api/vendor/tickets           # تیکت‌ها

# Public storefront
GET    /api/store/:slug              # صفحه فروشنده
GET    /api/store/:slug/products     # محصولات فروشنده
```

### 7.3 انتخاب فروشنده در صفحه محصول

```typescript
interface ProductPage {
  product: Product;
  offers: VendorOffer[];  // همه فروشندگان که این محصول را دارند
  showVendorSection: boolean; // فقط وقتی offers.length > 1
}

// اگر فقط یک فروشنده (یا فقط فروشگاه اصلی) داشته باشیم:
// showVendorSection = false
// قیمت فروشنده مستقیم نمایش داده می‌شود
```

---

> **یادداشت:** برای جلوگیری از سردرگمی، هر `VendorOffer` یک رکورد مجزا است. تأیید یا رد یک offer تأثیری روی محصول پایه ندارد.
